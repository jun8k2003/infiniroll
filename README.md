# Infiniroll - クリックホイール型論理スクロール・オーバーレイアプリ

Android端末における縦長ページのスクロール時の誤タップ（広告の誤爆等）を完全に防ぐための、iPodのクリックホイール風フローティング・コントローラーアプリです。

## 📁 ドキュメント構成
- **`SPEC.md`**: 本アプリの全体仕様書です。機能、アーキテクチャ、UI/UXデザインの定義を記載しています。
- **`SPEC_HISTORY.md`**: AIとの仕様変更、拡張、議論の決定履歴を追記・蓄積していくログファイルです。

## 🔄 仕様変更・拡張のルール
1. 本リポジトリの設計や機能の変更・追加を行う際は、まずAIとの対話を通じて議論・決定を行います。
2. 決定した内容および仕様の差分は、必ず **`SPEC_HISTORY.md`** に履歴として追記します。
3. 必要に応じて **`SPEC.md`** の該当セクションをアップデートし、最新の仕様状態を常に同期させます。
